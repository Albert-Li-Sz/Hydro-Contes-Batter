## 真实环境

在 Hydro 5.0.7、Node.js 24.21.0、MongoDB 及 CCS 环境中，使用 Browser 内置浏览器完成验收。

- 侧栏入口位于 CCS 重置项之后，支持延迟加载、重复注入处理和缺少 CCS 时的回退位置。
- 带域前缀的配置、预览、创建、播放、进度及删除接口通过。
- 完整执行 86 步滚榜，覆盖前进、回退、自动播放、奖项展示和重播。
- 刷新、服务进程重启及断线恢复后，从数据库恢复进度并保持暂停。
- HTTP 同版本并发写入返回 200 / 409，错误令牌及匿名访问被拒绝。
- 原有增强榜、分榜、奖牌和管理入口正常显示，配置及播放沿用 Hydro 页面框架。

真实 MongoDB 上的两个独立 Node 进程同时更新同一 revision，分别返回 200 和 409。不同管理员及同一管理员的多个会话保持独立。18 MiB 以上的快照拆分为 7 块，每块最多 4 MiB，重组校验通过。验收创建的会话与临时集合已清理，比赛数据验收前后的哈希一致。

浏览器流程使用一个管理员账号。多管理员权限组合由 Handler 测试与真实 MongoDB 隔离测试覆盖。PJAX 检查采用真实 Hydro 页面上的片段替换和事件重放。响应式尺寸模拟的验证范围为浏览器布局。
